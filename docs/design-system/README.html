1 · Principles · 60 / 30 / 10

The rule. Off-white is the canvas (60%). Dark green is ink, headers, active states, primary chrome (30%). Gold is emphasis — used sparingly on high-value surfaces (10%). Red and amber are semantic only — they appear exclusively inside status indicators where they communicate state (vencido / pendiente). Never decorative.
  • Canvas: #FFFEFC — every page background
  • Ink: #1B4332 — primary buttons, table headers, active tabs, icons, container left bars
  • Accent: #B8960C — gold for emphasis, inline-table headers, secondary CTAs on high-value actions
  • Semantic: red + amber only inside status pills

Content rules. No filler. No decorative iconography. Imagery placeholders are preferred over bad AI attempts. Density follows the data: sparse where the user reads, dense where they scan.

3 · Typography

Families: Inter (UI, body, headings, numbers) · Geist Mono (code only). Declared in src/app/globals.css as --font-sans / --font-mono. JetBrains Mono is not loaded by the app — the mockup pages in this folder still reference it for historical reasons; ignore that, the rule below is authoritative.

Numerics rule: any cell containing a number, date, or currency uses Inter with tabular-nums. Money always goes through <MoneyCell> (src/components/shared/MoneyCell.tsx), which applies tabular-nums font-medium + formatCurrency. Never hand-roll a money string.

6 · Badges & status pills

D pattern. All status badges share the same shape: tinted background · 3px colored left-bar · matching text color. Shape: padding: 3px 10px; border-radius: 3px; font-size: 10.5px; font-weight: 600; letter-spacing: 0.03em; border-left: 3px solid <color>;. Sentence case — no uppercase.

Faceted multi-select filter (shipped 2026-06-29)

The standard filter control for every toolbar (Contratos, Propiedades, Cobros, Gastos…). Empty it reads as a dashed + Label affordance; once values are picked the border goes solid green and the selection shows inline as up to two D-pattern mini-badges, collapsing to an N sel. count beyond that. The popover holds a type-to-filter search, a checkbox list, and a Limpiar filtro footer. Auto-sizes to content; pin a width via className only when alignment demands it.

⊕ Moneda ⊕ Moneda ARS ⊕ Grupo 3 sel.

Trigger height 32px, radius 6px. Dashed border #cfcfc7 → solid #1B4332 when active. Mini-badge = D-pattern tokens (bg #f0f6f2, text #0f2a1f, 2px green left-bar). Count badge drops the left-bar. Mini-badges truncate at 120px.

Component: src/components/shared/MultiSelectFilter.tsx. API: { label, options:[{value,label}], selected, onSelectionChange, className? } — unchanged, so all existing toolbars inherit the look. For a "Sin grupo"-style pseudo-option, prepend it to options in the caller.

10 · Money & numbers

$ 225.000 ARS 450.000 US$ 12.400,50

Single Intl-formatted string (es-AR currency style). Inter with tabular-nums for column alignment and font-medium (500) weight. Symbol shares the size and color of the digits — inherited from the parent. Use the ARS capsule in mixed-currency contexts. JetBrains Mono is not used for money — Inter at font-variant-numeric: tabular-nums gives mono-style column alignment without switching fonts.

<!-- in React: -->
<MoneyCell value={225000} currency="ARS" />
<!-- raw HTML equivalent: -->
<span class="money">$ 225.000</span>
<!-- .money = tabular-nums + font-medium; color/size inherited -->

17 · Toasts

White-card toast family (sonner toast.custom). One tarjeta blanca, redondeo 6px, sombra; chip de ícono redondo teñido por semántica (success green-50 · error red-50 · warning amber-50 · neutral panel); mensaje Inter 14px/500 + descripción opcional.

  • Variante con acción "Ver" + barra de countdown — éxito de creación o edición en la Cuenta Corriente (pago, cargo, plan, nota, alerta, liquidación, ticket). Botón outline verde con ícono, y barra gold que se vacía con el tiempo restante y se pausa al hover (patrón Discord/Gmail). Helper: toastSuccess(message, { onView, description?, duration? }) en src/lib/utils/toast-success.tsx.
  • Gemela "Deshacer" — misma tarjeta para borrados reversibles: toastDeletedWithUndo(...) en src/lib/utils/toast-undo.tsx.
  • Familia semántica plana (success / error / info / warning) — hoy vía richColors de sonner; el chip teñido es la dirección del DS.
Una sola familia de toast. Cualquier toast con acción o countdown sale de estos helpers — no armar toast.custom a mano ni volver al toast.success(msg, {'{'} action {'}'}) default (botón negro genérico, sin barra). Reference → components-toast.html
