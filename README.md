# West · Compras y pagos

Facturas, remitos, cuenta corriente y pagos a proveedores. Repo aparte que después se
une a la app de alquileres. Leer `CLAUDE.md` y `docs/` antes de tocar nada.

```bash
cp .env.example .env   # completar con la rama dev-app-compras
npm install
npm run dev
```

Usuarios: `npm run usuario -- "Nombre" email@west.com operador`
